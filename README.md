# AtmoSync – IoT Risk Analytics

AtmoSync is an IoT-based data analytics project designed to monitor environmental conditions inside agricultural shipping containers.

The project analyzes sensor parameters such as temperature, humidity, and vibration to identify abnormal conditions and classify container risk levels.

## Technologies Used

- Python
- Apache Kafka
- MySQL
- Pandas
- Jupyter Notebook
- Power BI

## Project Workflow

IoT Sensor Data
↓
Kafka
↓
MySQL
↓
Risk Engine
↓
Data Analysis
↓
Power BI Dashboard
